# Matrix Element Call 유튜브 음악 봇 🎵

Matrix의 최신 음성 통화(**Element Call / MatrixRTC**)에 접속하여 유튜브 음원을 재생하고 제어할 수 있는 Discord 스타일의 음악 봇입니다.

## 🌟 새로 추가된 스마트 기능 (음성 채널 자동 감지!)
- **채팅 채널과 음성 채널 분리 지원**:
  - `1`번 채팅방에 있으면서 `test` 음성 채널에 통화 중일 때, `1`번 방에서 `!play <링크>`를 입력하면 **봇이 사용자가 접속해 있는 `test` 음성 채널을 자동으로 찾아가서 음악을 재생**합니다!
- **음성 채널 명시적 지정 지원**:
  - `!play test <링크>` 와 같이 음성 채널 이름을 직접 지정하여 재생할 수도 있습니다.
- **채널 간 통합 제어**:
  - 봇이 `test` 음성 채널에서 재생 중일 때, `1`번 채팅방에서 `!skip`, `!stop`, `!volume`, `!queue` 등의 명령어를 그대로 사용할 수 있습니다.

## 🎮 명령어 안내

### 재생 및 대기열
| 명령어 | 축약형 | 설명 |
| :--- | :--- | :--- |
| `!play <URL / 검색어>` | `!p` | 유튜브 링크 재생 (내가 접속 중인 음성 채널로 자동 입장) |
| `!play <채널명> <URL>` | `!p` | 특정 음성 채널을 직접 지정하여 재생 (예: `!play test <URL>`) |
| `!queue` | `!q` | 현재 대기열 목록 및 남은 시간(ETA) 확인 |
| `!nowplaying` | `!np` | 현재 재생 중인 곡 제목 및 정보 표시 |
| `!skip` | `!s` | 현재 곡을 넘기고 다음 대기열 곡 재생 |
| `!stop` | `!x` | 재생 정지 및 대기열 전체 비우기 |
| `!loop` | `!lp` | 현재 재생 중인 대기열 반복 모드 토글 |
| `!history` | `!hist` | 최근 재생 기록 확인 |

### 음성 채널 제어
| 명령어 | 축약형 | 설명 |
| :--- | :--- | :--- |
| `!join` | `!j` | 내가 접속 중인 음성 채널로 봇을 수동 호출 |
| `!join <채널명>` | `!j` | 특정 음성 채널로 봇 호출 (예: `!join test`) |
| `!leave` | `!lv` | 음성 채널에서 퇴장 |
| `!volume <0-200>` | `!v` | 볼륨 조절 (기본: 100) |
| `!fadein <ms>` | `!fi` | 곡 시작 페이드인 시간 설정 (0-5000ms) |
| `!help` | `!h` | 사용 가능한 전체 명령어 도움말 표시 |
